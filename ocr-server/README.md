# 사진 채점 중계 서버 준비하기

공책 사진을 구글 Gemini에 보내 글씨를 읽어 오는 작은 서버입니다.
열쇠를 이 서버 안에만 두기 때문에, 공개된 학생 화면에는 열쇠가 나타나지 않습니다.

준비는 세 단계입니다. 한 번만 해 두면 그다음부터는 손댈 일이 없습니다.

## 1단계. 구글에서 열쇠 받기

1. [Google AI Studio](https://aistudio.google.com/apikey)에 구글 계정으로 들어갑니다.
2. **API 키 만들기**를 눌러 열쇠를 받습니다.
3. 받은 열쇠를 적어 둡니다. 아무에게도 알려 주면 안 되는 비밀번호입니다.

무료 등급은 결제 수단을 등록하지 않아도 쓸 수 있습니다. 공식 문서에도
유료로 올라갈 때 비로소 결제를 설정하라고 적혀 있습니다.

## 2단계. 중계 서버 올리기

[클라우드플레어](https://dash.cloudflare.com/sign-up)에 무료로 가입한 뒤, 이 폴더에서 차례대로 실행합니다.

```bash
npx wrangler login
npx wrangler secret put GEMINI_KEY
npx wrangler deploy
```

- `secret put`을 하면 값을 입력하라고 물어봅니다. 1단계에서 받은 열쇠를 붙여 넣습니다.
- 입력한 열쇠는 클라우드플레어 안에만 저장되고, 이 폴더의 파일에는 남지 않습니다.
- 마지막 `deploy`가 끝나면 `https://ys-ocr.○○○.workers.dev` 같은 주소를 알려 줍니다.

## 3단계. 앱에 주소 알려 주기

`index.html`에서 아래 줄을 찾아 2단계에서 받은 주소를 적습니다. (이미 적어 두었습니다.)

```js
let OCR_SERVER = 'https://ys-ocr.ocr-server.workers.dev';
```

주소가 적혀 있으면 받아쓰기를 마친 정답 화면에 **📷 공책 사진으로 채점하기** 단추가 나타납니다.
비워 두면 단추가 숨겨지고, 손으로 채점하는 방식 그대로 쓸 수 있습니다.

## 꼭 알아 둘 점

### 무료 등급은 사진이 구글의 제품 개선에 쓰입니다

구글은 요금 문서에서 무료 등급을 "Content used to improve our products",
유료 등급을 "Content **not** used to improve our products"라고 밝히고 있습니다.
그래서 **사진에 이름과 얼굴이 들어가지 않게** 하는 것이 중요합니다.
글씨만 찍히면 누구의 공책인지 알 수 있는 정보가 담기지 않습니다.
학생 이름이 적힌 공책이라면 그 부분이 나오지 않게 찍어 주세요.

### AI가 글씨를 잘못 읽을 수 있습니다

그래서 읽은 내용을 문장마다 보여 주고, ⭕❌를 눌러 바로잡을 수 있게 해 두었습니다.
마지막 판단은 사람이 합니다.

특히 AI는 **틀린 글자를 알아서 고쳐 읽으려는 버릇**이 있습니다. 그러면 틀린 답이
맞은 것으로 보일 수 있어, 서버에서 "보이는 그대로 옮기고 절대 고치지 말라"고
거듭 일러두었습니다. 그래도 완벽하지는 않으니 처음 몇 번은 사람이 견주어 보세요.

### 그 밖에

- **사진은 어디에도 저장되지 않습니다.** 글씨를 읽는 동안만 쓰이고 바로 사라집니다.
- **`wrangler.toml`의 `ALLOWED_ORIGINS`에 적힌 주소에서 온 요청만 받습니다.** 사이트 주소가 바뀌면 이 값을 고치고 다시 `deploy` 하세요.
- **모델이 붐비면 자동으로 다음 모델로 넘어갑니다.** `wrangler.toml`의 `GEMINI_MODEL`에 쉼표로 이어 적은 차례대로 시도합니다. 특정 모델이 자꾸 실패하면 그 이름을 빼고 다시 `deploy` 하세요.
- 사진 한 장을 읽는 데 **10~20초쯤** 걸립니다. 붐비는 모델을 건너뛰느라 더 걸릴 때도 있습니다.
